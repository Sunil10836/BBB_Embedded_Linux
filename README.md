# Counter Using 7-Segment Display and BeagleBone Black (BBB) (Embedded Linux)

**This project demonstrates how to interface a 7-segment display with the BeagleBone Black (BBB) using Embedded Linux (sysfs GPIO).**

This project implements a **Counter** on a **single-digit 7-segment display** using the **BeagleBone Black (BBB)**.

# Features:

**1. Up Counting : 0 to 9**

**2. Down Couting 9 to 0**

**3. Up and Down Couting :  0 to 9 and 9 to 0**

**4. Random Couting**

**5. Uses BBB GPIO pins via sysfs**


# Hardware Requirements:

**1. BeagleBone Black Rev-C**

**2. 7-Segment Display (Common Anode / Common Cathode)**

**3. 220Ω resistors × 7**

**4. Breadboard + Jumper wires**

# Software Requirements:

**1. Debian-based Embedded Linux running on BBB**

**2. GCC compiler**

**3. SSH access (PuTTY/ Eclipse remote)**

**4. Knowledge of Linux sysfs GPIO**
